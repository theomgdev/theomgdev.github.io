Hermes Agent

A personal, self-hosted automation assistant operated by Cahit Karahan.

Hermes Agent is an AI assistant that runs locally on my own computer. I use it as a working tool: it reads and writes files, runs shell commands, drives a browser, and calls APIs on my behalf so that I can automate parts of my own software engineering and personal admin work.

This is a single-user application. It is not a product, not a service, and it is not offered to other people. The only account it accesses is my own.

What it does with Google services

Hermes Agent connects to my own Google Account through Google's OAuth 2.0 flow, which I authorize manually on Google's consent screen. It uses that access for these tasks:

  • Gmail — read my inbox so the assistant can summarize and triage it, search my own mail history for context, and send or reply to messages when I explicitly ask it to.
  • Google Calendar — read my schedule for daily briefings, and create or remove events when I ask.
  • Google Drive, Docs and Sheets — read, create and edit my own documents and spreadsheets as part of automation tasks.
  • Google Contacts — look up a contact's address or phone number when I ask the assistant to reach someone.

Every one of these actions is initiated by me, in a chat session with the assistant, on my own machine.

Where it runs

The assistant runs on my personal computer. OAuth tokens are stored in a local configuration directory on that machine (%LOCALAPPDATA%\hermes\) and are never transmitted anywhere except to Google's own API endpoints. There is no server component, no shared backend, and no other user.
